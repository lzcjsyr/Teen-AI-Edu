# 技术与隐私说明

## 默认服务

- 生图：WorkBuddy 内置 ImageGen 工具（腾讯混元模型），助手在对话中直接调用，无需用户配置 API 密钥。
- 声音：小米 MiMo `mimo-v2.5-tts-voiceclone`。
- 合成：本地 FFmpeg，不上传最终视频。

## 生图工作方式

本 Skill 不再使用火山方舟豆包 API，改为使用 WorkBuddy 内置 ImageGen 工具：

1. 运行 `run.py prototype` 或 `run.py images` 时，脚本完成本地准备（归一化原画），为每张缺失图片打印 `IMAGE_PLAN`。
2. 助手解析计划，逐个调用 ImageGen 工具生成图片，保存到指定路径。
3. 再次运行同一命令，脚本执行本地后处理（加印角色名、生成结尾页、更新清单）。

**多角色一致性（方案 A）：** ImageGen 的 `image` 参数仅接受单张参考图。场景生成时传入原画作为风格参考，角色外貌通过文字描述在 prompt 中传达。角色原型阶段同样只传入原画。

## 尺寸

图片使用 1024×1536（3:4 比例）。最终视频在本地缩放为 1080×1440。结尾作品页使用 PIL 本地生成，尺寸同图片配置。

## 密钥

密钥只从环境变量或 `.env` 读取。日志只显示"已配置/缺失"，不得显示密钥值。生图不再需要外部密钥。配音仍需要 `MIMO_API_KEY`。

## 声音

- **声音克隆**：参考声音建议15-30秒，单人、近距离、无音乐。上传前获得录音者明确同意。脚本会生成24kHz单声道标准化副本用于上传。视频成功后默认删除这个副本，但不会擅自删除用户提供的原始文件。
- **如何触发声音克隆**：有两种方式，满足其一即可——
  1. 把参考录音放到项目的 `输入/声音参考.{wav/mp3/m4a…}`（或用 `init/all --voice 文件` 自动拷入）；**或**
  2. 在 `故事.docx` 的「配音音色」里填写 **`克隆音`**（模式关键词）。此时若项目 `输入/` 没有参考录音，脚本会自动回退到 Skill 自带的克隆样例 `资源/用户声音/声音参考.wav`。
- **注意**：`克隆音` 是**模式关键词**，不是音色名；运行 `voice` 时**不要**再加 `--preset`，否则会覆盖文档意图、强制走预置音色。若既无项目参考录音、又无自带样例，脚本才回退到官方预置音色。
- **预置声音（内置音色）**：如果项目 `输入/` 下没有提供任何 `声音参考.*` 语音文件、且未指定 `克隆音`，程序将自动转为使用小米官方内置的 `mimo-v2.5-tts` 模型合成音频，不需要上传或保留任何参考声音。默认的内置音色配置如下：
  * `白桦` (成年男)
  * `茉莉` (成年女)
  * `苏打` (年轻男/男童)
  * `冰糖` (年轻女/女童)
  这些声音可以在 `资源/官方预置声音/` 目录下找到生成好的样例文件供提前试听。

## 数据最小化

- 项目使用编号或昵称；上传原画前确认创作者同意将其发送给生图服务。
- 外部提示词不包含创作者真实姓名。
- 不上传家庭地址、学校、班级和联系方式。
- 不将克隆声音用于本次作品以外的用途。
