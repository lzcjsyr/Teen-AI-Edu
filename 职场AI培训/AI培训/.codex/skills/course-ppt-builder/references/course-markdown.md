# 课程 Markdown 生成与修订规则

本 reference 用于阶段一：生成或修订优创Hub AI 培训课程 Markdown。

## 使用时机

- 用户还没有提供 Markdown，需要先创建课程 Markdown 文件
- 用户已经提供 Markdown，需要检查并修订为可转课件的结构
- 用户要求“先生成 md”“先给我课程稿”“修改某一页课程内容”

如果用户只要求生成或修订 Markdown，完成后必须停下来让用户确认，不要继续生成 PPTX 或 HTML。

## 输出文件

课程 Markdown 默认输出到课程文件夹根目录，文件名使用 `课程稿.md`，例如：

```text
第一课/课程稿.md
```

如果 `课程稿.md` 已存在，不要覆盖，创建 `课程稿第二版.md`、`课程稿第三版.md` 等中文版本文件。只生成或修订 Markdown 时，不要创建 `课件成品/`；`课件成品/` 只用于后续展示版本。

## Markdown 必须使用的课程页格式

每个课程单元都要用这个标题格式。这里的“第 N 页”只表示课程页序号，用于稳定解析页码：

```markdown
#### 【第 N 页：页面标题】
```

每个课程单元下面建议包含：

```markdown
**定位**

- 说明这一单元在课程中的作用

**页面设计**

- 页面类型：封面 / 课程地图 / 概念解释 / 流程 / 案例 / 提示词 / 总结等
- 主视觉：可选，用一句话描述希望读者看到的画面关系；不确定可留空
- 画面内容：列出真正需要出现在页面上的短句、标签、步骤或卡片
- 底部结论：如有，用一句人话收束本单元
- 设计提醒：说明需要避免的误区，例如“不要做成普通 bullet 页”

**讲者备注**

- 写讲课人可以照着说的一人称口播稿，像演讲者视图里的小抄；不作为页面可见内容
```

## Markdown 的内容特点

课程 Markdown 要符合这些要求：

- 面向没有 AI 基础的听众
- 少用抽象名词，多用工作场景和具体动作
- 每个课程单元只讲一个重点
- 文字要能直接转成页面内容，不写长篇文章
- 理论页要尽量配一个通俗比喻或真实工作例子
- 实操页要写清楚输入、动作、输出、人工检查点
- 总结页用短语，不写大段解释
- 每个课程单元都要有 `**页面设计**`，把内容、视觉表达和学习流程位置写在一起
- `**页面设计**` 要体现信息层级：页面类型、主视觉、页面短句、底部结论、设计提醒不要混在一起
- 每个课程单元最后都要有 `**讲者备注**`，用第一人称、口语化短段落写成讲课人可以直接说出口的话；不要写成“本页要讲什么”的说明，也不要混进 `**页面设计**`
- 页面设计要提示后续 HTML 的信息关系和构图意图。课程页标题、主视觉、画面内容、底部结论和设计提醒分别承担不同作用，不要写成一段混合说明。
- `设计提醒` 是设计约束和反模式提示，不是页面构图方案。生成 HTML 时要参考它避开错误做法，再根据页面类型、画面内容、课程节奏和前端信息设计最佳实践，自主决定构图、留白、层级、组件和视觉节奏。
- 不要使用 ASCII 线框或粗糙缩略图，避免误导后续图片生成或网页实现
- 设计提醒要具体指出本单元不应该做成什么样，例如“不要堆满解释文字”“不要做成普通目录页”

## 推荐课程结构

优创Hub AI 培训课程默认采用这类结构：

```markdown
# [课程名]

> **用途**：按一单元一重点的结构整理课程草稿，便于转成最终课件。
> **总时长**：**60 分钟**

**课程基本信息**

- 目标听众：优创Hub 同事
- 前置要求：[如有]

**课程时间安排**

| 时段 | 时长 | 内容 |
| --- | --- | --- |
| 0′–20′ | 20 min | 基础概念 |
| 20′–50′ | 30 min | 实操案例 |
| 50′–60′ | 10 min | 总结答疑 |
```

正文按章节组织，每个课程单元都用 `#### 【第 N 页：页面标题】`。这个格式只用于解析页码和课程单元，不决定最终呈现形式。

## 单元编号要求

- 编号必须从 1 开始连续递增
- 不允许跳号、重复编号
- 标题要短，适合放在区块标题或视觉主标题位置
- 附录索引如果存在，要和正文编号一致

## 用户确认点

完成 Markdown 后，先停下来让用户确认。

建议回复：

```text
Markdown 课程稿已经整理好。请先确认每个课程单元的内容和顺序是否合适；确认后我会再确认最终呈现方案：图片版 PPTX，或 HTML 连续滚动分页课程页面。
```

如果用户要求修改某一页或某个课程单元，只修改对应单元和必要索引，不要重写整份文档。
