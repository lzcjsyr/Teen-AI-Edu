# 优创Hub AI 培训课程课件生成

这个 Skill 用来统一生成优创Hub AI 培训课程资料。核心流程是：先生成或修订课程 Markdown，等用户确认内容，再明确最终呈现方案，最后生成图片版 PPTX 或 HTML 连续滚动分页课程页面。

默认不要一上来直接生成最终课件。除非用户明确说“直接全部生成”，否则先交付 Markdown 草稿并等待确认。用户确认 Markdown 后，如果没有明确选择“图片版 PPTX / 每页一张图 / image_gen / PPTX”或“HTML / 网页版课件 / 打开一个 HTML 文件 / 连续滚动网页”，必须反问最终呈现方案。

## 阶段路由

| 用户意图                                                               | 执行动作                                                                                                                  |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 生成课程稿、先生成 md、修订 Markdown，或没有已确认 Markdown            | 读取 `references/course-markdown.md`，生成或修订 Markdown，然后停下来等用户确认 |
| 已确认 Markdown，且用户选择图片版 PPTX / 每页一张图 / image_gen / PPTX | 读取 `references/imagegen-pptx.md`，生成页面图片并合成 PPTX                                                             |
| 已确认 Markdown，且用户选择 HTML / 网页版课件 / 连续滚动网页讲义       | 读取 `references/html-continuous-slides.md`；实际生成或大幅重写 HTML 时，可读取 `references/html-page-templates.md` 作为轻量构图参考，不套固定模板 |
| 用户说“继续做最终课件”“生成成品”“做最后呈现”，但未说明形式       | 反问选择图片版 PPTX 还是 HTML 连续滚动分页课程页面                                                                        |

反问话术：

```text
Markdown 已确认。最后呈现我可以做两种形式：
1. 图片版 PPTX：每页一张图，再合成 PPTX。
2. HTML 连续滚动分页课程页面：一个 HTML 文件，按课程流程连续向下阅读，每页有清楚页码和分隔。

你希望用哪一种？
```

用户说“PPT”时可能只是借用这个词表达“可展示的课程成品”，不要自动理解成 `.pptx`。只有用户明确要求 PPTX、每页一张图或传统播放文件时，才走图片版 PPTX。用户明确要求 HTML 时，默认走 HTML 连续滚动分页课程页面；HTML 不固定 16:9，但必须一页一单元、页码统一、分页明显。只有用户明确要求“16:9 页面 / 一页一屏 / 像幻灯片一样逐页展示 / 键盘翻页”，才在 HTML 中采用固定 16:9 页面模式。

## 输出目录

同一课的产物必须放在同一个课程文件夹下，例如 `第一课/`。如果输入材料位于某个课程文件夹内，以该课程文件夹作为输出根目录；如果用户明确指定课程目录，以用户指定目录为准。

阶段一生成或修订的课程 Markdown 默认放在课程文件夹根目录，文件名用 `课程稿.md`。如果已存在，不要覆盖，创建 `课程稿第二版.md`、`课程稿第三版.md` 等中文版本文件。只生成 Markdown 时，不要创建 `课件成品/`。

展示成品才放进中文成品文件夹，默认 `课件成品/`。HTML、PPTX、页面图片、页面摘要 JSON、插图、字体等展示相关文件都放在这个文件夹内，建议结构：

```text
第一课/
├── 课程稿.md
└── 课件成品/
    ├── 课程网页.html
    ├── 图片版课件.pptx
    ├── 页面摘要.json
    ├── 页面图片/
    │   ├── 第01页.png
    │   └── 第02页.png
    └── 资源/
        ├── 图片/
        └── 字体/
```

产物文件夹和内部资源子文件夹必须使用中文命名。不要使用 `generated_ppt/`、`generated_html/`、`images/`、`assets/` 等英文目录名，也不要把最终产物散落在项目总根目录或 Skill 目录中。如果 `课件成品/` 已存在，不要覆盖已有输出；创建中文版本目录，例如 `课件成品第二版/`、`课件成品第三版/`。

## 交付内容

完整执行图片版 PPTX 时至少交付：

1. 课程 Markdown 文件
2. 页面图片目录，例如 `页面图片/`
3. 图片版 `.pptx` 文件
4. 简短说明：输入文件、页数、图片目录、PPTX 路径

完整执行 HTML 连续滚动分页课程页面时至少交付：

1. 课程 Markdown 文件
2. `.html` 课件文件
3. 如使用本地图片或字体等资源，交付同一课件文件夹内的中文资源目录
4. 简短说明：输入文件、页数、HTML 路径、打开方式

最终回复要写清楚：

- Markdown 文件路径
- 最终产物路径：PPTX 文件路径或 HTML 文件路径
- 如生成图片版 PPTX，写明图片目录和总页数
- 如生成 HTML，写明页数、页面区块数量、截图抽查页面和自我修复情况

## 检查要求

图片版 PPTX 按 `references/imagegen-pptx.md` 的交付前检查执行。

HTML 连续滚动分页课程页面按 `references/html-continuous-slides.md` 的交付前检查执行。生成 HTML 后必须做截图抽查和必要的自我修复，不要只依赖静态代码检查。

## 不适用场景

不要用本 Skill 处理：

- 用户要求制作可编辑原生 PPT 图形和文字；此时应改用原生 PPT 生成方式
- 用户要求做非优创Hub AI 培训主题的通用演示文稿，除非明确希望复用这套课程生产格式
- 用户只想讨论课程内容，不需要生成文件

## 注意事项

- 图片版 PPTX 的文字不可直接编辑。
- 每个阶段都可以单独执行；用户只要求生成 Markdown 时，不要继续生成最终课件。
- 用户未确认 Markdown 前，不要擅自进入最终生成阶段。
