# 固定分类标准

本文件是采购明细分类的业务规则来源。分类代码、科目名称和边界属于既定标准，使用时不得改名、合并、拆分或新增科目。

| 代码 | 科目 | 典型内容 |
| --- | --- | --- |
| 1403.01.01 | 荤食类 | 猪、牛、羊、鸡、鸭、鹅、鱼、虾、蟹等肉类、蛋类、肉制品 |
| 1403.01.02 | 蔬菜辅菜类 | 蔬菜、豆制品、腌菜、菌菇、干货 |
| 1403.01.03 | 主食类 | 米、面、粉、面包、馒头、花卷等 |
| 1403.01.04 | 粮油调味 | 油、盐、酱、醋、香料、味精、糖、火锅底料等 |
| 1403.01.05 | 饮品原料 | 牛奶、椰浆、果汁、豆奶、饮料等 |
| 1403.01.06 | 包装类 | 食品袋、打包盒、保鲜膜等 |
| 1403.01.07 | 低值易耗 | 餐巾纸、手套、洗洁精、锅铲、围裙等非食材消耗品 |

## 分类判断原则

- 根据商品本质和使用场景分类，不只看单个关键词。
- 品牌、产地、规格、重量、头数、加工方式和包装方式通常是修饰信息，不改变商品本质。
- 肉类、海鲜、蛋类和肉制品归入荤食类；蔬菜、豆制品、菌菇、腌菜和干货归入蔬菜辅菜类。
- 米面粉和常见面制主食归入主食类；油盐酱醋、香辛料、糖和复合调味品归入粮油调味。
- 牛奶、椰浆、果汁、豆奶和饮料等归入饮品原料。
- 食品袋、打包盒和保鲜膜等与食品包装直接相关的物品归入包装类。
- 餐巾纸、手套、清洁用品、厨具和围裙等非食材消耗品归入低值易耗。
- 无法完全确定时，仍从这 7 类中选择最接近的一类，并在复核清单里记录，不创建“其他”或“待确认”科目。
