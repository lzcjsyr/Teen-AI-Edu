# 联网下载主体图说明

这份说明只在需要真实人物、公司、产品、地点或现场画面时使用。
默认不要加载它。

## 什么时候用

- 文章里出现了足够具体的主体，真实图片比抽象插图更有信息价值
- 需要让读者一眼识别某个人物、产品、办公室、门店、工厂、发布会或现场
- 该图承担的是识别、代入和情境锚定，不承担完整论证

如果图片表达的是抽象关系、结构分层、趋势机制或观点转场，默认仍优先 API 图或本地 HTML 解释图。

## 来源优先级

优先顺序如下：

1. 官方网站、官方新闻稿、媒体素材页、投资者关系页面
2. 政府、大学、研究机构等主体公开页面
3. Wikimedia Commons
4. Unsplash、Pexels、Openverse 等来源清晰的图片站

不要直接使用来源不明、带明显水印、页面堆满营销元素、无法确认主体真伪的图片。

## 工作步骤

1. 先明确要找的主体，以及这张图对应正文哪一段。
2. 联网搜索 2 到 4 张候选图，优先搜横图。
3. 把候选图下载到项目目录，例如 `images/_download_candidates/`。
4. 下载后必须打开本地图片逐张视觉复核，不要只看搜索结果缩略图。
5. 选中后再移动或复制到 `images/` 的正式文件名，例如 `03-openai-campus.jpg`。
6. 在研究笔记或图片清单里记录图片来源页面，便于后续核验和替换。
7. 如果找不到合格横图，就不要硬用竖图，回退到 API 图或本地解释图。

## 视觉复核

至少检查：

- 主体是否真的是要表达的人物、公司、产品或地点
- 构图是否适合横向插入，优先 16:9 或至少宽大于高
- 主体是否足够突出，缩到手机宽度后仍能快速识别
- 清晰度是否足够，避免糊图、压缩痕迹、截图感过强
- 是否有明显水印、边框、拼贴、字幕条或大面积文字覆盖
- 画面语气是否和正文一致，避免过度戏剧化、猎奇或广告感过强

## 实用约束

- 优先真实照片，不优先海报、广告图、活动 KV 或带大标题的宣传图
- 优先单一主体明确、背景干净、焦点清楚的图
- 能找到横图时不要裁竖图硬凑；实在只能用竖图时，优先放弃该方案
- 不要把下载图当作证据本身；事实判断仍然回到正文来源
- 最终插入 `.docx` 的必须是本地图片文件，不要热链网络 URL
